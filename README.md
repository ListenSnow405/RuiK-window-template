# 科协之窗单期页面模板

科协之窗按学年分期，如"2025-2026学年第一期"。每一期在主站上有自己的页面（`ruik.xin/window/2025-2026/1` 这样的地址），整页由你来设计：版式、配色、字体、动画都可以和主站、和别的期不一样。这个模板让你在自己的仓库里做页面、随时预览，做好以后交给开发合进主站。

## 开始

1. 用这个模板建一个你自己的仓库：在仓库页面点 **Use this template**；或者下载 ZIP 解压，在文件夹里 `git init`。一期一个仓库，仓库名带上学年和期数，比如 `window-2025-2026-4`。
2. 装好 [Node.js](https://nodejs.org/)（22 或更新）和 pnpm（`npm install -g pnpm`），在文件夹里运行：

   ```bash
   pnpm install
   pnpm dev
   ```

   装依赖很慢的话，先换成国内的镜像源：`pnpm config set registry https://registry.npmmirror.com`。

3. 浏览器打开 `http://localhost:5173`，改 `src/issue/` 里的文件，页面会自动刷新。
4. 边做边运行 `pnpm lint`，它会检查下面《规则》里的各条，把问题一次全列出来，每条都写了怎么改。交付前 `pnpm lint` 和 `pnpm build` 都要通过，`pnpm build` 通过说明代码没有类型错误。

**只有 `src/issue/` 会合进主站**，其他文件只是本地预览用的外壳，不用改。`src/issue/index.tsx` 默认导出的组件就是整个页面，可以在 `src/issue/` 里再拆出别的组件和样式文件。

## 规则

页面怎么做由你定：可以装任何 npm 包（图表、动画、3D、公式渲染都行），可以请求接口或数据文件，可以嵌 B 站视频的 iframe。只有下面几条是为了不伤到主站和读者：`pnpm lint` 在本地就能查出来，合进主站时还会再查一遍，过不了的要改完才能合并。

**不碰读者的登录信息**

你的页面和主站在同一个网站下运行，读者的登录信息存在浏览器里。所以：

- 不读写 `localStorage`、`sessionStorage` 和 cookie。页面要记住什么（比如答题进度），放在组件的 state 里。
- 只引用 npm 包和 `src/issue/` 里自己的文件，不引用主站自己的代码。
- 不用 `eval`、`new Function`，审核的人看不出它们执行了什么。

**样式不影响主站**

- 自己写的样式放在 `.module.css` 里，每个选择器都以类名开头。可以写 `.page h1`，不能直接写 `h1`、`body`、`*`：这些会作用到整个主站，读者看完你这一期点回科协之窗，主站的标题也会跟着变样。
- 给第三方库的样式改外观时，写成 `.page :global(.katex) { … }`，前面套上自己的类名。
- npm 包自带的 CSS（比如 `import 'katex/dist/katex.min.css'`）可以直接引入。
- 整页的底色、字体写在最外层元素的类名上，示例里是 `.page`。

**大文件不放进来**

- `src/issue/` 里单个文件不超过 200 KB。小图标、小图可以放进来，用 `import 图片 from './xxx.webp'` 引用。主站服务器带宽很小，大图、视频、字体文件要传到 COS 的 `public/site/window/<学年>/<期数>/` 下，用开发给你的 `https://...` 地址。
- 不要用 `/xxx.webp` 这种以 `/` 开头的地址引用模板 `public/` 文件夹里的东西，合进主站后就找不到了。
- 图片先压缩：宽不超过 1600px，用 WebP 或 JPEG。
- 想用特别的字体，先只保留页面上用到的字（做成子集，一般几十 KB）。字体、要用 `fetch` 读的数据文件也可以放 COS，主站已经能跨域读取。本地预览固定用 `http://localhost:5173`，COS 只认这个地址；端口被占用时 `pnpm dev` 会直接报错，关掉占用它的程序再启动。主站的标题字体 `--font-display` 只含主站自己用到的字，不要用它。

**依赖的版本**

- `react`、`react-dom`、`antd`、`@ant-design/icons` 和主站共用，不要改它们的版本。
- 合并时你装的包会加进主站，同一个包主站只装一个版本。别的期已经用了的包，跟着它的版本；交付时说一下装了哪些包。
- 包越大，读者打开你这一期越慢（只影响你这一期，不影响主站别的页面）。差不多的库挑小的。

**版面**

- 左上角有主站的"科协之窗"返回按钮（预览里也有），距顶部和左边 16px、高 44px。别把标题、按钮放在它底下，页面顶部留出约 80px。
- 手机上也要能看：在浏览器开发者工具里切到 390px 宽，不能出现横向滚动条，字不能小到要放大才能读。
- 图片写 `alt`（说明图里是什么），文字和底色的对比要够，浅灰字配白底读不清。

## 交付

页面做好后交给开发，或者自己在主站仓库提 PR，二者择一：

- **交给开发**：先确认 `pnpm lint` 通过，再把 `src/issue/` 整个文件夹、要传到 COS 的大文件、`package.json` 里你加的包，以及这一期的目录信息发过去。目录信息包括学年、学年内第几期、标题（24 个字以内）、一两句摘要、发布日期，可选一张 4:3 的封面图。
- **自己提 PR**：把 `src/issue/` 复制成主站仓库的 `apps/web/src/window-issues/<学年>/<期数>/`（如 `2025-2026/1/`），加的包装进 `apps/web`，在 `apps/web/src/content/window.ts` 最前面加上这一期的目录信息，运行 `pnpm lint` 和 `pnpm test` 都通过后提 PR。
